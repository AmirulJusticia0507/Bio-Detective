# Skills

Keterampilan yang dibutuhkan tim pengembangan Bio-Detective.

## Core
- Desain game edukasi & narasi forensik
- Simulasi kimia/biokimia (reagen, pH, kromatografi, serologi, DNA fingerprinting)
- UI/UX interaktif, canvas rendering (Pixi.js/HTML5 Canvas)
- Backend API & rules engine
- Database modeling & migrasi

## Domain Knowledge
- Toksikologi: uji Biru Prusia (sianida), FeSO₄ + FeCl₃
- Kromatografi Lapis Tipis (TLC), nilai Rf
- Serologi ABO/Rhesus, aglutinasi
- Elektroforesis gel DNA fingerprinting
- Inhibisi enzim respirasi selular

## Tooling
- Vue 3 / React, Vite, Tailwind CSS
- Node.js (Express/NestJS) atau Python (FastAPI)
- PostgreSQL / MongoDB
- JWT Auth, WebSocket
- Git, CI/CD
